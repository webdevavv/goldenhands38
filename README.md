# Золотые ручки — HTML / CSS / JavaScript

Откройте `index.html` двойным щелчком. Установка, npm, Next.js и сборка не нужны. Можно загрузить всю папку на обычный статический хостинг.

## Файлы

- `index.html` — вся главная страница, услуги, отзывы и окно контактов.
- `styles.css` — оформление, мобильная версия и анимации.
- `script.js` — меню, появление секций, галерея, окно контактов, уведомление cookie.
- `assets/images/` — три сгенерированных примера маникюра.
- `assets/fonts/` — локальный Manrope и лицензия.
- `privacy.html`, `consent.html`, `terms.html`, `cookies.html`, `promo-terms.html` — редактируемые шаблоны документов.

## Что работает

Плавное появление секций при прокрутке, лёгкое движение карточки в первом экране, эффекты наведения, увеличение фотографий, мобильное меню, закреплённая кнопка записи, раскрытие FAQ. Анимации отключаются при системной настройке уменьшения движения. Контент доступен и без JavaScript.

Сайт работает как визитка. Все кнопки записи открывают окно с Instagram, телефоном и электронной почтой. Формы и отправки заявок нет. Никаких CRM, аналитики или базы данных нет. Уведомление сохраняет только факт закрытия в localStorage.

## Фотографии и отзывы

Три изображения созданы встроенным ImageGen, а не сняты в студии. На сайте они подписаны как ИИ-примеры. Промпты сохранены в `IMAGE-PROMPTS.md`.

Имена и тексты в трёх карточках отзывов вымышлены для демонстрации оформления. Это явно указано над блоком и в каждой карточке. Перед коммерческой публикацией замените их реальными отзывами и добавьте источники; не убирайте маркировку у вымышленных отзывов.

Цены и график не придуманы: посетитель видит «по запросу». Фотографии заменяются в `assets/images/`, тексты — непосредственно в HTML. Адрес и телефон взяты из исходного задания.

Документы остаются шаблонами: перед публичным запуском заполните реквизиты и согласуйте тексты с фактическими процессами. Предыдущая версия Next.js сохранена отдельно в соседней папке `goldenhands38`, она не нужна для работы этой версии.

Контакты модального окна редактируются в `index.html`, блок `#booking-dialog`. Другие социальные сети не добавлены: ссылки на них не были предоставлены.
